# university-labs

Demo code for the Dapr University labs and tracks.

This repo was called `ai-agent-tracks-instruqt` until November 2026. It was renamed because it now
holds code for labs that aren't about AI agents, such as Dapr 101, pub/sub and secrets.

GitHub redirects the old name to this repo, and the live Instruqt 1.0 AI agent tracks still clone
it by the old URL. **Never create a new repo named `diagrid-labs/ai-agent-tracks-instruqt`.** That
would break the redirect and those tracks.
